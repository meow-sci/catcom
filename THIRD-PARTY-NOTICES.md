## Notes on provenance

- All license texts were downloaded on 2026-10-16 (LLVM and mingw-w64: 2026-10-17) with `curl -fsSL` from the URLs in the table. npm tarballs were extracted into scratch directories, and only their license files were copied.
- The sucrase bundle does not record its dependency versions. The versions of lines-and-columns and ts-interface-checker above are the latest releases that satisfy sucrase 3.35.1's ranges. A string search of the bundle found code from both packages, and found no code from sucrase's other dependencies (mz, pirates, commander, tinyglobby, @jridgewell/gen-mapping).
